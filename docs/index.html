Ranking uses the least-squares linear fit y = c + m·t (t in years) over the selected window: either the raw slope m (the metric's change per year in its own units) or — the default — the %metric form of it. R² is how much of the variance that straight line explains: green ≥ 0.8 (the slope is a faithful summary), amber 0.5–0.8 (trend with real wobble), grey < 0.5 (the slope is NOT a reliable description — treat with caution). %EPS / %Rev/sh / … (v1.16.0) is the UNITLESS trend measure: the slope divided by the metric's LATEST value (e.g. %EPS = EPS slope $/yr ÷ current TTM EPS), per year — so companies of any size compare directly. Blank when the latest value is near or below zero, where a percentage would be noise. FILTER LEVELS (v1.17.0) stack with AND logic: a company must pass every level (e.g. Fit R² ≥ 0.8 AND P/E ≤ 30 AND gross margin ≥ 40%) before it is ranked; companies missing a filtered value are excluded.
